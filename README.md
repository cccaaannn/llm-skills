## Install

Claude Code:
```
/plugin marketplace add cccaaannn/llm-skills
/plugin install cccaaannn@llm-skills
```
Other: `npx skills add cccaaannn/llm-skills`

## Skills

1. `/cccaaannn:review-like-can` Extremely strict code review in the style of me, this is very subjective hance the name. Skill is unnecessary strict and a little funny.
2. `/cccaaannn:audit-like-can <path>` Runs the review for the whole codebase or a path.
